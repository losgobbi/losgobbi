# Rodrigo Gobbi

Senior Software Engineer with a systems background — I like being close to the metal, but I don't stay in one lane (and I'm always moving... :upside_down_face:).

## History

**Telecommunication.** Developed different things over time like network daemons that were running on Linux systems, CLI for them (Cisco style) so that they could be configured and SNMP agents for monitoring their status. Most of the time, arch was PowerPC/ARM with an external Broadcom chipset.

**Finance.** created embedded software for Point-of-Sale (POS) devices like SmartPOS (running Android) and PinPAD (running RTOS). For both, worked across the foundation (AOSP/BSP/drivers and firmware) and the application level.

**Smartphone manufacturer/Android.** Was responsible for Android platform (AOSP) stability and performance across multiple smartphone products at different areas like Android Framework services to application crashes, system crashes, boot performance, SELinux (AVC) violations and Linux Kernel interactions.

**Platform & infrastructure.** Worked on a high-performance network traffic inspection systems running on globally distributed Ubuntu hosts.
          
**Linux kernel contributor (free time).** some patches accepted upstream in the Linux kernel, across different subsystems.
